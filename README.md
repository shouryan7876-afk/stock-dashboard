📈 Stock Dashboard with Candlestick Analysis
A modern, responsive stock market dashboard built with HTML, CSS,
JavaScript, Node.js, and Express.js. It visualizes historical stock
price movements through candlestick charts and displays key market
statistics.
✨ Features
- Search stocks by ticker symbol (for example, AAPL or MSFT)
- Interactive historical candlestick charts
- Latest closing price and price-change display
- Daily high and low price range
- Trading volume statistics
- Modern dark-themed interface
- Responsive dashboard layout
- Backend API integration for retrieving stock data
🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Axios
- dotenv
- Lightweight Charts
- Yahoo Finance data source

🚀 Run Locally
Prerequisites
Install Node.js (LTS version recommended).
Installation
1. Clone the repository:
   git clone https://github.com/shouryan7876-afk/stock-dashboard.git
2. Open the project folder:
   cd stock-dashboard
3. Install dependencies:
   npm install
4. Start the server:
   npm start
5. Open your browser and visit:
   http://localhost:3000
Keep the terminal running while using the dashboard.
📊 How to Use
1. Open the dashboard in your browser.
2. Enter a stock ticker symbol, such as AAPL or MSFT.
3. Run the search/analyze action.
4. Review the candlestick chart and the available price and volume
   statistics.
